# Portfolio Responsivo - Trends IT

Projeto de portfólio desenvolvido com foco em responsividade, organização visual e boas práticas de front-end.

## Sobre o projeto

Este projeto consiste em um site de portfólio moderno e totalmente responsivo, criado para apresentar projetos, habilidades e informações profissionais de forma clara e acessível em diferentes dispositivos.

A proposta foi aplicar conceitos de **mobile first**, garantindo uma boa experiência tanto em telas menores quanto em desktops.

## Objetivos

- Praticar desenvolvimento responsivo (mobile first)
- Melhorar organização de layout com HTML e CSS
- Criar uma interface limpa e profissional
- Simular um portfólio real para uso profissional

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries

## Responsividade

O projeto foi desenvolvido seguindo a abordagem **mobile first**, com adaptações progressivas para:

- 📱 Mobile
- 📲 Tablet
- 💻 Desktop
